# DLink

网盘分享链接 → 直链 → 多线程下载。浏览器扩展取直链，桌面程序下载，**不劫持浏览器原生下载**。

> 一个自用的下载工具。核心价值不是"破解限速"（那件事本文档会诚实地告诉你做不到），
> 而是：**把各家网盘的取链流程统一成一次点击，并按各平台的限速特性自动选对下载策略。**

---

## 它做什么

```
┌──────────────┐   直链+鉴权   ┌───────────────┐
│ 浏览器扩展    │ ───────────> │  桌面下载器    │
│ 读登录态      │              │  队列/进度     │
│ 解析分享页    │              │  分段并行      │
└──────────────┘              └───────────────┘
```

- **扩展**：在分享页提取直链（能读到 `HttpOnly` cookie 和页面内的 `jsToken`，这些 Python 拿不到）
- **下载器**：通用下载引擎，按平台策略决定用几路并发
- **不劫持**：不注入浏览器的下载流程，只在你点按钮时工作

## 平台支持与限速真相

| 平台 | 取直链 | 限速类型 | 实测速度 | 推荐线程数 | 并行有效？ |
|---|---|---|---|---|---|
| **普通 HTTP 链接** | 直接粘贴 | 取决于服务器 | 4 路 8.19 MB/s（单连接 4.91） | **4–8** | ✅ 多数有效 |
| **腾讯微云** | ✅ | **连接级**（单连接约 14MB 后降到 240B/s） | 8 路聚合 **9.7 MB/s** | **8** | ✅ **有效** |
| **百度网盘** | ✅ | **账号级配额**（恒定 80 KB/s） | 1 路 80KB/s；8 路 → 9KB/s | **1** | ❌ **无效且更差** |
| **夸克网盘** | ✅（需转存） | **二阶段**（窗口期/限流期） | 窗口期 15–20 MB/s；限流期约 2 MB/s | **6** | ⚠️ 仅窗口期 |
| **UC 网盘** | ⚠️ 代码就绪 | 推测同夸克 | 未实测 | **6** | ⚠️ 未验证 |

### 为什么推荐值不同？这是本工具最有价值的部分

**微云**：限的是「连接年龄」，单连接下到 14MB 左右就掉到 240 B/s，但**新连接立刻恢复满速**。
所以拆成 32MB 段、8 路并行。实测在 1.5GB 级文件上约 2 分钟完成。

**百度**：是**账号级总带宽封顶**。实测数据：

| 并发 | 聚合速度 |
|---|---|
| 1 路 | 75 KB/s |
| 3 路 | 130 KB/s |
| 8 路 | **9 KB/s**（6 路返回 403） |

单连接 40 秒实测**稳定在精确的 80.0 KB/s**，零波动 —— 服务端硬编码。
换直链、换 CDN、换 UA、换 clienttype、改 Range **全部无效**。

权威佐证（BaiduPCS-Go 作者原文）：
> 普通用户请将 `max_parallel` 设为 1，调大线程数只会在短时间内提升下载速度，
> 且极易很快触发限速，**导致几小时至几天内账号在各客户端都接近 0 速**。
> 本软件不支持普通用户提速。

**所以本工具对百度设 `force_single: true`。** 这不是妥协，是实测得出的正确配置。

**夸克**：二阶段限速。窗口期能跑 15–20 MB/s，18:00–23:00 可能被限到约 2 MB/s。
6 路是折中值，限流期建议手动降到 2。

**普通链接**：多数服务器不限总量，但**单连接常常跑不满带宽**。
实测同一文件：单连接 4.91 MB/s → 4 路 8.19 MB/s（**1.7x**）→ 8 路 3.07 MB/s（**反而变慢**）。
所以 8 路不是无条件最优，可在设置里按需调低。

> ⚠️ 上表的百度/微云数据是本机 2026-11 实测，会随平台策略变化。
> 遇到不符的情况欢迎提 issue 附上你的实测数据。

## 安装

### 方式一：直接用打包好的 exe（推荐）

1. 从 [Releases](../../releases) 下载 `DLink.exe`
2. 双击运行 —— **后端和界面都会自动启动**，无需安装 Python
3. 装浏览器扩展：菜单 **帮助 → 导出浏览器扩展…**，选一个文件夹，
   程序会把扩展释放到那里的 `dlink-extension/` 子目录
4. 在浏览器里：`edge://extensions/` → 开启「开发人员模式」
   → 「加载解压缩的扩展」→ 选刚才那个 `dlink-extension` 文件夹

> exe 是**自包含**的：扩展文件也打包在里面，不需要另外下载。

### 方式二：从源码运行

```bash
pip install -r requirements.txt

# 一条命令启动（后端 + 界面）
python launch.py

# 或者分开启动，便于调试
python src/dlink/server.py       # 终端 1：后端
python -m dlink.gui              # 终端 2：桌面界面
```

- 后端只监听 `127.0.0.1`，不对外暴露
- GUI 是 **PySide6 原生桌面窗口**（黑白配色）

### 浏览器扩展（源码方式）

1. 打开 `edge://extensions/` 或 `chrome://extensions/`
2. 开启「开发人员模式」
3. 点「加载解压缩的扩展」，选择本仓库的 `extension/` 目录

## 使用

1. 在**已登录**的浏览器打开网盘分享页
2. 右下角点「↓ 提取直链」（或点扩展图标）
3. 点「发送到下载器」
4. 文件下到设置里的保存目录（默认 `下载/DLink`，**可在设置里改，改完重启仍生效**）

**普通链接**：点 GUI 的「＋ 添加链接」，粘贴任意 `http(s)` 地址即可（每行一个）。

### 界面能看到什么

```
┌ DLink 下载器 ───────────────────────────────────────────┐
│ ＋添加链接  全部暂停  全部继续  清除已完成  打开目录  设置 │
├──────┬──────┬──────┬────────┬──────┬────┬────┬────┤
│ 名称  │ 进度  │ 速度  │  大小   │剩余时间│直链 │平台│状态│
├──────┼──────┼──────┼────────┼──────┼────┼────┼────┤
│ 镜像.iso│▬▬ 100%│  —  │1.5/1.5GB│  —  │ —  │百度│已完成│
└──────┴──────┴──────┴────────┴──────┴────┴────┴────┘
```

- **直链**列显示链接剩余有效期（百度 8h / 夸克 6h / 微云 2h）
- **自动续链**：下载中途链接过期时，任务转为「等待续链」，扩展会在 20 秒内收到通知、重新取链，然后**从断点继续**（不重下）
- **速度**做了 3 秒平滑：百度恒定 80KB/s 时不会显示成 `0/240/0` 的锯齿
- 速度为 0 显示 `—` 而不是 `0 KB/s`（避免误以为断了）

## 接管浏览器下载（v0.2.0 新增，默认关闭）

开启后，浏览器里发起的下载会被**取消并转交 DLink**，由 DLink 多线程完成，
浏览器下载栏里不再出现这个文件。

**默认关闭**，而且开启后**默认只接管网盘链接**（百度 / 夸克 / UC / 微云），
其他文件仍由浏览器下载。

### 第一次会先问一次

第一次遇到网盘下载时，扩展会把这个下载**暂停**（不是取消），然后弹出窗口：

1. 说明 DLink 要接管什么；
2. 让你选「接管并转到 DLink」或「保持浏览器下载」——后者**原样续传，不丢文件**；
3. 告诉你以后在哪里改。

直接关掉窗口 = 「保持浏览器下载」。

> 为什么用「暂停」而不是「取消」：取消之后只能重新发起请求，会丢掉 POST 表单体、
> 自定义请求头和一次性签名。暂停能保留完整下载上下文，`resume()` 就继续。

### 在哪里改

- **扩展面板顶部开关**：只做开 / 关
- **扩展图标 → 右键 → 选项**：接管范围（只接管网盘 / 全部接管）、放行域名、
  最小文件大小、是否弹系统通知
- **选项页还有两个按钮**：「放行下一次下载」（临时踩一次刹车）、
  「重新弹一次询问窗口」

### 三种接管不了的情况（是设计限制，不是 bug）

| 情况 | 原因 | 实际行为 |
|---|---|---|
| `blob:` / `data:` 下载 | 内容只存在于页面内存，外部程序拿不到 | 直接放行给浏览器 |
| `.m3u8` / `.mpd` | 这是分片清单，不是文件 | 直接放行 |
| POST 表单下载 | 取消后无法原样重放 | 转交失败 → 自动回退浏览器下载 |

另外：**DLink 没运行时一律放行**，绝不会出现「拦下来了又发不出去」。
还有一点要知道：接管来的下载**没有分享页信息**，直链中途过期时无法自动续链
（会明确报错，不会卡住等），从分享页正常取直链的任务不受影响。

### ⚠️ 升级提示

v0.2.0 新增了 `downloads` 权限，浏览器可能把已安装的扩展**自动禁用**，
需要到 `edge://extensions/` 重新启用并确认授权。
不开接管功能时，扩展行为与 v0.1.0 完全一致。

## 配置

### 分平台下载策略

设置页里**每种网盘和普通链接分开配置**，因为它们的限速机制完全不同：

```json
{
  "direct": { "workers": 8, "seg_size": 33554432 },
  "baidu":  { "workers": 1, "force_single": true },
  "weiyun": { "workers": 8, "seg_size": 33554432 },
  "quark":  { "workers": 6, "seg_size": 16777216 },
  "uc":     { "workers": 6, "seg_size": 16777216 }
}
```

存于 `%LOCALAPPDATA%/dlink/profiles.json`。

### 全局设置

- **保存目录**（改完立即生效，且**重启后仍保留** —— 存在 `%LOCALAPPDATA%\dlink\settings.json`）
- 同时下载任务数（默认 3，避免一次推送 100 个文件就开 100 个并发）
- 是否校验
- **下载完成后是否清理夸克转存的临时文件**（默认关闭，避免万一失败却把源删了）

配置文件位置：

| 文件 | 内容 |
|---|---|
| `%LOCALAPPDATA%\dlink\settings.json` | 保存目录、并发任务数、开关 |
| `%LOCALAPPDATA%\dlink\profiles.json` | 各平台的并发/分段策略 |
| `%LOCALAPPDATA%\dlink\hosts.json` | 按站点学到的并发数 |

### 按主机记忆并发（GUI 设置里可查看/重置）

不同 HTTP 站点的并发特性差异极大，所以程序会**记住每个站点上次有效的并发数**：

- 首次用平台默认（8 路）
- 只有出现大量连接被拒/超时才下调（减半）
- **只降不升**——成功后保持，避免在两组值之间来回震荡
- 存储于 `%LOCALAPPDATA%/dlink/hosts.json`，可在设置里逐条忘记

## 扩展新平台

**核心设计目标：加一个平台只写一个文件，不改核心代码。**

### 后端

1. 新建 `src/dlink/platforms/<name>.py`，实现：

```python
class MyAdapter:
    name = "mysite"
    display_name = "我的网盘"

    @staticmethod
    def match(url: str) -> bool: ...
    @staticmethod
    def parse_id(url: str) -> str: ...
    def resolve(self, url, **opts) -> list[RemoteFile]: ...
    def get_direct_link(self, url, f=None, **opts) -> DirectLink: ...
    def recommended_workers(self) -> int: ...
```

2. 在 `src/dlink/profile.py` 的 `BUILTIN` 里加默认策略 + 说明文案
3. 写 `tests/test_platform_<name>.py`

### 前端（扩展）

1. `extension/injected.js` 加一个 `resolveXxx()` 函数，并在注册表里加一行
2. `extension/platforms.js` 加平台识别规则
3. `extension/manifest.json` 的 `host_permissions` 和 `content_scripts.matches` 加上域名

### 文档

4. `docs/PLATFORMS.md` 补一节实测数据
5. 本 README 的表格加一行

详见 [`design/EXTENSIBILITY.md`](design/EXTENSIBILITY.md)。

## 已知限制

1. **百度就是 80KB/s**，除非开 SVIP。工具不破解，也不建议任何破解手段。
2. **夸克会转存**：分享文件不能直接取直链，扩展会自动转存到你网盘根目录，需要自己清理。
3. **直链有时效**：百度 8h、夸克 6h、微云约 2h。
   已实现**自动续链**：过期后扩展会重新取链并断点续传（最多 5 次）。
   若浏览器关着或扩展被禁用，任务会停在「等待续链」，打开浏览器即可恢复。
4. **同名文件**：自动加 `(1)`、`(2)` 后缀，不覆盖。
5. **UC 未实测**：代码写好了但没有测试账号。
6. **接管下载是可选功能**，默认关闭；`blob:` / HLS / POST 下载无法接管（见上一节）。
