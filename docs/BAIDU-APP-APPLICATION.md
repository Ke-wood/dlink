# 百度网盘开放平台 · 应用申请文案

> 用途：在 <https://pan.baidu.com/union/console/applist> 注册应用时需要填这些字段。
> 直接把下面各段贴进对应输入框即可，按需要删减。
> 目标只有一个：**拿到 OAuth 的 `client_id` / `client_secret`**，然后用设备码授权换 `access_token`，
> 从而通过 xpan 的 `multimedia?method=filemetas` 拿到可离线使用的直链。

---

## 1. 应用名称

```
DLink
```

（备选：`DLink 下载助手`、`DLink Desktop`）

## 2. 应用类型

选 **桌面应用 / 其他（PC 客户端）**。

> 不要选 Web：Web 需要备案域名和回调地址；桌面应用可以走**设备码模式**，不需要回调地址。

## 3. 一句话简介（表单里通常限 50 字内）

```
一款本地运行的多线程下载器，通过网盘开放接口下载用户本人有权访问的文件。
```

更短的备选：

```
本地多线程下载器，仅下载用户自己的文件。
```

## 4. 应用详情 / 使用场景（300–500 字，主要审核就看这段）

```
DLink 是一款在用户自己电脑上运行的开源下载管理工具（Windows 桌面程序，Python + Qt 实现）。

要解决的问题：
网盘网页端下载大文件时，浏览器无法断点续传、不能排队、不支持多线程分段，
网络中断后需要从头下载。用户希望用一个本地程序，把自己网盘里的文件按队列下载下来，
并且能断点续传、失败重试、事后校验文件的 MD5/SHA1 是否完整。

具体功能：
1. 授权后读取用户本人网盘的文件列表，让用户勾选要下载的文件；
2. 通过开放接口获取这些文件的下载地址，在本机多线程分段下载；
3. 下载完成后校验文件哈希，发现不一致则提示重新下载；
4. 支持任务队列、暂停/继续、限速、下载完成后打开所在目录。

调用方式：
- 采用「设备码模式」完成 OAuth 授权，用户在浏览器里输入一次授权码即可；
- 之后使用 refresh_token 自动续期，不要求用户重复授权；
- 仅调用基础文件接口（文件列表 / 文件信息 / 获取下载地址），不做上传、删除、重命名等写操作。

数据与隐私：
- 程序完全在本机运行，没有任何自建服务端；
- access_token / refresh_token 仅保存在本机配置文件（%LOCALAPPDATA%\dlink），不上传、不共享；
- 不采集、不统计、不传输用户的文件内容与文件名；
- 代码开源，可审计。

使用人群：
主要是需要长期备份或搬运自己网盘资料的个人用户，单人使用，不对外提供服务。
```

## 5. 权限范围（Scope）

勾选 **`basic`** 与 **`netdisk`** 即可，不要多勾。

实际会调用的接口：

| 接口 | 用途 |
|---|---|
| `GET /rest/2.0/xpan/nas?method=uinfo` | 授权后显示当前账号昵称（确认授权对象） |
| `GET /rest/2.0/xpan/file?method=list` | 列出用户自己网盘的文件 |
| `GET /rest/2.0/xpan/multimedia?method=filemetas&dlink=1` | 获取文件下载地址 |

不使用：上传、删除、分享、转存、通讯录、相册等任何其他能力。

## 6. 回调地址 / 授权方式

- 授权方式选择 **设备码模式（Device Code）**
- 回调地址：**留空**（设备码模式不需要）

## 9. 审核可能追问，以及建议回答

| 追问 | 建议回答 |
|---|---|
| 为什么不直接用网页下载？ | 网页端无法断点续传、不能排队；大文件中断要重下。这是本地下载器的常规需求。 |
| 会不会把直链提供给第三方？ | 不会。直链仅在本进程内用于下载，不落盘、不上传、不分享。 |
| 会不会用作「不限速下载」？ | 不会。程序完全遵守账号本身的限速，实测就是 80–130 KB/s，没有做任何绕过。 |
| 是否需要分享链接解析能力？ | **不需要**。本应用只处理用户**自己网盘里**的文件；分享链接的转存/解析不在申请范围内。 |
| 会不会批量搬运他人资源？ | 不会。单人使用，仅限账号本人文件。 |

> ⚠️ 关键：**不要把申请写成「网盘分享链接解析/直链提取工具」**。
> 开放平台对「分享解析」非常敏感（那属于另一套需要资质的接口），
> 而我们要的只是「用户下载自己网盘文件」，这是最普通、最容易过的场景。
> 我们的实际用途也确实如此：分享文件会先**转存到用户自己网盘**，再当作自有文件下载。

## 10. 拿到凭据之后

凭据到手后告诉我，我来实现：

1. 设置页新增 `client_id` / `client_secret` 两个输入框（存本机，不进仓库）
2. 设备码授权：点「授权」→ 显示 `user_code` 和授权链接 → 轮询拿 token
3. `refresh_token` 落盘，`access_token` 到期自动续
4. 取链改用 `xpan/multimedia?method=filemetas&dlink=1&access_token=...`
5. 下载器直接吃这条链（`Referer` / `User-Agent` 已在 2026-11-16 修好）

预期结果：**百度网盘和微云一样全自动**，不再依赖任何第三方解析助手。
