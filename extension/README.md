# 安装与使用

## 一、加载扩展到 Edge

1. 打开 Edge，地址栏输入：
   ```
   edge://extensions/
   ```
2. 打开左下角的 **「开发人员模式」** 开关
3. 点 **「加载解压缩的扩展」**
4. 选择目录：
   ```
   D:\plan\HANDOFF-direct-link-tool\extension
   ```
5. 装好后工具栏会出现蓝色下载箭头图标（可能需要点「扩展」拼图图标固定）

---

## 二、启动下载器

打开终端（PowerShell 或 CMD）：

```powershell
cd D:\plan\HANDOFF-direct-link-tool
$env:PYTHONPATH="src"
python src\dlink\server.py
```

看到下面这行就说明启动成功：

```
DLink 下载器已启动：http://127.0.0.1:8765
```

**保持这个窗口开着**。默认保存到 `%USERPROFILE%\Downloads\DLink`。

---

## 三、使用

1. 在**已登录**的浏览器里打开网盘分享页，例如：
   - `https://pan.baidu.com/s/xxxxx?pwd=abcd`
   - `https://pan.quark.cn/s/xxxxx`
   - `https://share.weiyun.com/xxxxx`
2. 右下角会出现蓝色悬浮按钮 **「↓ 提取直链」**，点它
3. 或者点工具栏的扩展图标 → **「提取直链」**
4. 等解析完成，列出文件后点 **「发送到下载器」**
5. 文件下载到 `Downloads\DLink\`

---

## 四、当前支持状态

| 平台 | 解析 | 取直链 | 实际下载 | 备注 |
|---|---|---|---|---|
| 百度网盘 | ✅ | ✅ | ✅ | 分享直链，无需转存 |
| 夸克网盘 | ✅ | ✅ | ✅ | 需要转存（自动） |
| UC 网盘 | ⚠️ 代码就绪 | ⚠️ 未验证 | ⚠️ 未验证 | 缺测试账号 |
| 腾讯微云 | ✅ | ✅ | ✅ | 需要登录 |

## 五、已知限制

### 1. 大目录解析慢
夸克分享 178 个文件时，逐个取直链会很慢。
目前默认**只取前若干个直链**（可配置），其余标记为「未取直链」。

### 2. 直链有时效
- 百度：8 小时
- 夸克：约 6 小时
- 微云：更短

**取到就尽快下载**，过期需要重新解析。

### 3. 平台限速无法突破
- 百度：约 80 KB/s（账号级配额，并发无效）
- 夸克：时段限速（18:00-23:00 可能降到 2MB/s）
- 微云：连接级限速，**8 路并行可达 9.7MB/s**

详见 `docs/PLATFORMS.md` 与 `docs/BAIDU-BYPASS-FINAL.md`。

### 4. 夸克会转存文件到自己网盘
夸克的分享文件不能直接取直链，扩展会自动转存到你网盘根目录。
**需要自己清理**（扩展暂未做自动删除）。

## 六、排错

### 扩展显示「下载器未运行」
- 确认终端里的 `python src\dlink\server.py` 还在运行
- 确认没有被防火墙拦截（只监听 127.0.0.1，一般不会）
- 点扩展图标后它会自动重试探测（3 秒一次）

### 点「提取直链」没反应
- 确认当前页面是**分享页**（URL 含 `/s/`）
- 确认已登录（未登录只能解析，取不到直链）
- 打开 `edge://extensions/` → 找到扩展 → 点「服务工作进程」查看报错

### 百度提取码问题
- 先在页面里**手动输入提取码**通过一次
- 然后重新点「提取直链」

### 夸克 412 错误
- 说明 Cookie 没带上。检查扩展是否正确读取 cookie
- 确认用的是**客户端 UA**（扩展已内置）

### 解析出来是空列表
- 页面可能还没加载完，等几秒重试
- 百度分享如果没有提取码但需要，会返回空

---

## 七、卸载

`edge://extensions/` → 找到 DLink → 「删除」
