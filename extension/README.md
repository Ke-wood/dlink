# 安装与使用

## 一、加载扩展到 Edge

1. 打开 Edge，地址栏输入：
   ```
   edge://extensions/
   ```
2. 打开左下角的 **「开发人员模式」** 开关
3. 点 **「加载解压缩的扩展」**
4. 选择目录：
   ```
   <本仓库>/extension
   ```
5. 装好后工具栏会出现蓝色下载箭头图标（可能需要点「扩展」拼图图标固定）

---

## 二、启动下载器

打开终端（PowerShell 或 CMD）：

```powershell
cd <本仓库>
$env:PYTHONPATH="src"
python src\dlink\server.py
```

看到下面这行就说明启动成功：

```
DLink 下载器已启动：http://127.0.0.1:8765
```

**保持这个窗口开着**。默认保存到 `%USERPROFILE%\Downloads\DLink`。

---

## 三、使用

1. 在**已登录**的浏览器里打开网盘分享页，例如：
   - `https://pan.baidu.com/s/xxxxx?pwd=abcd`
   - `https://pan.quark.cn/s/xxxxx`
   - `https://share.weiyun.com/xxxxx`
2. 右下角会出现蓝色悬浮按钮 **「↓ 提取直链」**，点它
3. 或者点工具栏的扩展图标 → **「提取直链」**
4. 等解析完成，列出文件后点 **「发送到下载器」**
5. 文件下载到 `Downloads\DLink\`

---

## 四、接管浏览器下载（v0.2.0 新增，可选）

不开这个功能，扩展和以前一模一样：只负责从分享页取直链。

### 打开

两种方式，效果相同：

- 扩展面板顶部的 **「接管浏览器下载」** 开关
- 扩展图标 → 右键 → **选项**（完整的设置页）

**默认只接管网盘链接**，其他文件浏览器照常下载。想要全部接管，在选项页把
「接管范围」改成「接管所有下载」—— 注意这意味着扩展能看到你所有的下载地址。

### 第一次会先问一次

第一次遇到网盘下载时：

1. 扩展把这个下载**暂停**（不是取消，浏览器里能看到它在下载栏里停住）；
2. 弹出一个小窗口，说明接管什么 + 让你选「接管并转到 DLink」/「保持浏览器下载」，
   并告诉你以后在哪里改；
3. 选「保持浏览器下载」会**原样续传**，文件不会丢。

直接关窗口 = 保持浏览器下载。之后不再询问，想重新问一次：
选项页 →「重新弹一次询问窗口」。

### 接管之后发生了什么

- 浏览器里那个下载被取消，临时文件被清掉
- DLink 里出现同名任务，按平台策略下载（**百度仍然是 1 路**，见限速说明）
- 扩展图标闪一下角标 `↓`，并弹一条系统通知（可在选项页关掉）

### 接管不了的情况

| 情况 | 为什么 | 行为 |
|---|---|---|
| `blob:` / `data:` 下载 | 内容只在页面内存里 | 放行，不接管 |
| `.m3u8` / `.mpd` | 分片清单，不是文件 | 放行，不接管 |
| POST 表单下载 | 取消后无法重放 | 转交失败 → 自动回退浏览器下载 |
| DLink 没运行 | —— | 放行，不拦截 |

### 排错

**升级后扩展不见了 / 被禁用**：新增了 `downloads` 权限，去 `edge://extensions/`
重新启用。

**开关打开了但下载还是走浏览器**：检查选项页里 DLink 是否「在线」；
只接管网盘模式下，非网盘域名本来就不接管；也可能是该下载属于上表的「接管不了」。

**想临时用浏览器下一次**：选项页 →「放行下一次下载」。

## 六、已知限制

### 1. 大目录解析慢
夸克分享 178 个文件时，逐个取直链会很慢。
目前默认**只取前若干个直链**（可配置），其余标记为「未取直链」。

### 2. 直链有时效
- 百度：8 小时
- 夸克：约 6 小时
- 微云：更短

**取到就尽快下载**，过期需要重新解析。

### 3. 平台限速无法突破
- 百度：约 80 KB/s（账号级配额，并发无效）
- 夸克：时段限速（18:00-23:00 可能降到 2MB/s）
- 微云：连接级限速，**8 路并行可达 9.7MB/s**

详见 `docs/PLATFORMS.md` 与 `docs/BAIDU-BYPASS-FINAL.md`。

### 4. 夸克会转存文件到自己网盘
夸克的分享文件不能直接取直链，扩展会自动转存到你网盘根目录。
**需要自己清理**（扩展暂未做自动删除）。

## 七、排错

### 扩展显示「下载器未运行」
- 确认终端里的 `python src\dlink\server.py` 还在运行
- 确认没有被防火墙拦截（只监听 127.0.0.1，一般不会）
- 点扩展图标后它会自动重试探测（3 秒一次）

### 点「提取直链」没反应
- 确认当前页面是**分享页**（URL 含 `/s/`）
- 确认已登录（未登录只能解析，取不到直链）
- 打开 `edge://extensions/` → 找到扩展 → 点「服务工作进程」查看报错

### 百度提取码问题
- 先在页面里**手动输入提取码**通过一次
- 然后重新点「提取直链」

### 夸克 412 错误
- 说明 Cookie 没带上。检查扩展是否正确读取 cookie
- 确认用的是**客户端 UA**（扩展已内置）

### 解析出来是空列表
- 页面可能还没加载完，等几秒重试
- 百度分享如果没有提取码但需要，会返回空

---

## 八、卸载

`edge://extensions/` → 找到 DLink → 「删除」
